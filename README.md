# Web Traffic Analytics

## Project Overview
This project analyzes website traffic data to understand user behavior and website performance.

## Objectives
- Analyze page views.
- Study session duration.
- Identify bounce rate patterns.
- Analyze traffic sources.
- Understand user engagement.
- Study conversion rates.

## Technologies Used
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn

## Project Structure
- dataset/
- output/
- main.py
- requirements.txt
- README.md

## How to Run
1. Install Python.
2. Install requirements using:
   pip install -r requirements.txt
3. Run:
   python main.py

## Output
Generated charts, cleaned dataset and analysis report are saved in the output folder.
